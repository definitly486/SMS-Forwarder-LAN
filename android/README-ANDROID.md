# Android-приложение

1. Открой эту папку (`android/`) в Android Studio (File → Open).
2. Дождись синхронизации Gradle (Android Studio скачает wrapper и зависимости).
3. Положи свой `cert.pem` в `app/src/main/assets/cert.pem` (для HTTPS).
4. Build → Build Bundle(s) / APK(s) → Build APK(s) или используй GitHub Actions.

Минимальные требования: Android Studio Hedgehog+ / JDK 17.
